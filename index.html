이미지를 먼저 글로 정확하게 해석한 뒤, 그 결과를 JSON으로 변환해 캘린더에 반영하는 2단계 방식입니다.
딱 이 순서대로 하면 달력에 들어갑니다
사이트가 이미지를 직접 읽는 것은 아니에요. ① 사이트에서 프롬프트 복사 → ② 대화창에 이미지와 함께 전송 → ③ 받은 글을 사이트에 붙임 → ④ JSON 변환 명령을 다시 대화창에 전송 → ⑤ 받은 JSON을 사이트에 붙여 저장 순서입니다.

아직 저장되지 않음
대화창에서: 예약시트 사진을 첨부하고 방금 복사한 영문 프롬프트를 같은 메시지에 붙여 보내세요. 답변은 JSON이 아니라 ROOM / GUEST NAME / CHECK-IN / CHECK-OUT 등이 적힌 긴 글 설명으로 나와야 정상입니다.
대화창에서: 이번에는 이미지가 필요 없습니다. 방금 복사한 JSON 변환 명령만 새 메시지로 보내고, 돌아온 { 로 시작해서 } 로 끝나는 JSON 전체를 복사하세요.
중요: ②에는 이미지 해석 글, ④에는 JSON을 넣어야 합니다. 서로 바꾸어 넣으면 작동하지 않습니다. 시트 기준일은 위에서 선택한 날짜로 사이트가 고정합니다.
